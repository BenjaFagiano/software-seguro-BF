El Handshake TLS es un cifrado diseñado para proteger las comunicaciones a través de Internet, donde se transforma la tecnología deprecada como el HTTP a una conexión segura HTTPS. 
El TLS cumple tres funciones, la primera es la confidencialidad que cifra la comunicación entre el cliente y el servidor para evitar que un atacante o terceros, puedan leer o modificar información.
Autenticación, verifica la autenticidad de sitios garantizando que el usuario se está conectando a un sitio seguro.
Y por último Integridad, es que realiza verificaciones para comprobar que los datos enviados no fueron alterados.
